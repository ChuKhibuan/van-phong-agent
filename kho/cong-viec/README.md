# Hồ sơ công việc

Mỗi việc đã hoàn tất có một file `<năm>-<tháng>-<mã việc>.md`, ví dụ `2026-11-A12.md`. QA đưa file vào đây sau khi kiểm tra.

## Mẫu hồ sơ

```markdown
# <Mã việc>: <tên việc>

- Ngày nhận / ngày xong:
- Khách (chỉ ghi tên gọi, không ghi số điện thoại, số tài khoản):
- Các phòng đã làm: Báo giá → … → Giao hàng & CSKH
- Đầu ra: <link Drive / đường dẫn file trên máy chủ>
- Điểm cần nhớ cho lần sau:
- QA duyệt ngày:
```
