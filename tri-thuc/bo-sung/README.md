# Bổ sung cho skill chuyên môn

Skill chuyên môn (`.claude/skills/vit-media`, `hoang-ha-makeup-video`, `so-tay-thiet-ke`) nằm trong `.claude/`, agent chạy tự động không ghi được.
Kiến thức mới thuộc các skill đó ghi vào đây: `<tên-skill>-<chủ-đề>.md` (ví dụ `vit-media-dinh-gia.md`). Đọc file ở đây **cùng với** skill gốc; chỗ nào mâu thuẫn thì bản ở đây mới hơn.
Chủ hoặc Claude phiên chính định kỳ gộp vào skill gốc rồi xoá file ở đây.
